Recommendation ranking

I worked on ranking for asset recommendations. The existing model scored each user and asset pair on its own with binary cross-entropy. I replaced it with a contrastive InfoNCE objective over user and asset embeddings, which turns the problem into picking the right asset out of a set of candidates. That is the same shape as the ranking metric we cared about, mean reciprocal rank.

The negatives matter as much as the loss. In-batch negatives are mostly easy, so I added negatives chosen to be hard for the model instead of relying on the batch alone. Together this improved MRR by 50% over the binary cross-entropy baseline.
