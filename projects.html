Systems and inference optimization for transformer serving

June 2026 to August 2026

Built a serving stack from nanoGPT and benchmarked latency and memory across three paths: a naive implementation, a KV cache, and custom kernels. The custom path uses a verified Triton implementation of FlashAttention, which splits attention into blocks and uses an online softmax so the full attention matrix never sits in GPU memory.

Extended the stack to serve many requests at once with continuous batching, so new requests join a running batch instead of waiting for it to finish. Paged KV-cache management stores each request's cache in fixed-size pages, so concurrent requests share GPU memory with little waste.

Latent dynamics in diffusion models

December 2025 to January 2026

Examined the denoising process of a diffusion model and described it with a simple dynamical system. I compressed MNIST into a 16-dimensional latent space with a VAE, trained a diffusion model in that space, and recorded more than 100 denoising trajectories.

Applied SINDy, sparse regression over a library of polynomial and exponential terms, to find interpretable equations for how the latent state evolves during denoising.
